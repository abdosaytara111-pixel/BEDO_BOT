# Highrise Bot (Cleaned Version)

This directory contains a clean, optimized version of the Highrise Bot.

## Directory Structure

- **root/**:
  - `main.py`: The consolidated bot logic and manager.
  - `config.json`: Configuration for your room and bot token.
  - `start_bot.bat`: Double-click to start the bot.
  - `requirements.txt`: Required Python packages.

- **settings/**: Contains all room settings files.
  - `settings_ROOMID.json`: Specific settings for each room.
  - `settings.json`: Template settings file.

- **data/**: Contains data resources.
  - `emotes.json`: List of emotes.
  - `bot_emotes.json`: Custom emote lists.
  - `location.json`: Saved location points.

## How to Run

1.  **Install Python** (if not installed).
2.  **Double-click `start_bot.bat`**. 
    - This will install strict dependencies and launch your bots.
